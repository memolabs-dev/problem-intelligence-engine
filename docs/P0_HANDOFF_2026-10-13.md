# P0 — Technical completion and independent-validation handoff

Date: 2026-10-13 · Memo Labs Dev · Problem Intelligence Engine

## Technical workflow implemented

- Public-source discovery with source hashes and original-thread lineage; source-root-aware LLM selection.
- Evidence-grounded extraction, independent model screening and model-run persistence.
- Local 384-dimensional production pgvector (`all-minilm`) and separate in-memory alternative retrieval (`nomic-embed-text`).
- Audited semantic reviews of alternate leads with pinned source extraction IDs, policy-scoped cached decisions, a second source freshness check and explicit model/service error states.
- Complete-link problem grouping with valid historical corroboration edges retained across invocations.
- Deterministic, source-leakage-aware, blinded human annotation queue; private offline two-reviewer UI; rubric and disagreement/coverage evaluator.
- Main protected by required Node 22/24 + PostgreSQL CI; contributor bot may auto-merge after green checks.

## Evidence and remaining acceptance criteria

As of this handoff, two bounded batches of six alternate-model leads produced **12 new semantic reviewer decisions**: **1 `same_problem`, 11 `different_problem`, 0 errors**. The total database contains **2 model-confirmed same-problem edges** and **18 different-problem edges**. These are **model decisions**, not independently labeled ground truth.

The current local benchmark pilot has **150 unlabeled pairs** and **fails the pre-annotation quality gate**:

- 0 pairs above the configured high-similarity cutoff of 0.60 in the current `all-minilm` development pool.
- 7 distinct Hacker News original discussions in cross-platform comparisons, below the gate's minimum of 8.
- Source selection and earlier automatic judgments can introduce sampling bias; these are not population-level metrics.

Therefore the **technical implementation is ready for independent evaluation**, but **P0 independent validation is NOT finished** and GitHub issue #3 must remain open. Do not claim recall, semantic precision or market fit from the development corpus or LLM-generated verdicts.

## Private review pilot on maintainer Mac

Private directory: `~/.local/share/memolabs/pie/p0-annotation-pilot-20261013/` (not committed to GitHub). It contains frozen source queue, sampling audit, SHA-256 manifest, blank independent reviewer templates, browser-based reviewer A/B HTML pages and a machine-readable quality-gate result.

The files are a **pilot**, not a passing holdout. Keep the audit separate from annotators; they should only see `pairs-blind.json` or the generated reviewer HTML. Collect two independent human judgments of source-grounded candidate pairs and independently authenticate review independence outside the tool. Reviewers must not see each other's answers or existing model verdicts. Before a publishable benchmark, mine more challenging cross-thread, cross-community positive candidates and freeze a *new*, passing holdout with no prior tuning/review leakage. Adjudicate disagreements and publish test-set composition, coverage and uncertainty together with any metrics. The pipeline must not fill human review templates automatically.

For a completed, valid holdout use `npm run eval:review-holdout -- <blind.json> <reviewer-a.json> <reviewer-b.json> [predictions.json]` and retain original submissions and adjudication evidence. Never close P0 #3 until those two independent human annotation sets and a genuinely qualifying holdout exist.
